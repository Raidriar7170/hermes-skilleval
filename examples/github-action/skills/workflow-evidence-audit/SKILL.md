# Workflow Evidence Audit

Use this skill to inspect workflow evidence, regenerated artifacts, gate
reports, and review packets before a maintainer review. Confirm that artifacts
are deterministic and that paths point to repo-local evidence.

Do not use for running a hosted service or deciding final release approval.

## Evidence Cues

- validation workflow evidence
- regenerated artifacts
- diagnostic gate report
- maintainer review
