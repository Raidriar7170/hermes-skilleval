# Release Note Review

Use this skill to review release notes, changelog drafts, and maintainer-facing
summaries before they are shared. Check that evidence links are present,
boundaries are visible, and non-goals are stated plainly.

Do not use for writing product launch copy or approving a release.

## Evidence Cues

- release notes
- evidence boundaries
- non-goals
- local validation summary
