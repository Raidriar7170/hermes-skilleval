# External Repo Action Smoke Pack

This pack records a local external-consumer smoke for the Reusable GitHub
Action RC. It shows the shape an independent repository would use: local
`skills/`, local `benchmark/`, an output directory named `skilleval-output`,
and the root composite action called by `uses: Raidriar7170/hermes-skilleval@main`.

The committed outputs were generated by copying the public example fixture into
a temporary consumer repository, executing the composite action's "Run
SkillEval gate" shell step with consumer-relative `skills`, `benchmark`, and
`skilleval-output` paths, and then copying the generated output files back into
this evidence pack. A reviewer can inspect the gate decision without creating a
remote repository, adding secrets, publishing a tag, or running hosted GitHub
Actions.

Boundary: this is local external-consumer smoke and local RC evidence, not a
Marketplace Action release, not hosted GitHub Actions proof, not GitHub API PR
comments, not PR annotations, not SaaS, not a runtime MCP router, not a SOTA
claim, not benchmark status, not production readiness, not release approval,
not automatic merge approval, and not a v0.2.0 release.

## Consumer Workflow Shape

See [`.github/workflows/skilleval.yml`](.github/workflows/skilleval.yml) for a
minimal consumer workflow example. In a real consumer repository, `skills/` and
`benchmark/` are owned by that repository:

```yaml
- uses: Raidriar7170/hermes-skilleval@main
  with:
    skill-path: skills
    benchmark-path: benchmark
    min-recall-at-k: "1.0"
    max-negative-hit-rate: "0.0"
    output-dir: skilleval-output
    upload-artifacts: "true"
```

## Local Reproduction

The committed output mirrors the action shell smoke covered by
`tests/test_reusable_github_action_rc.py`: it runs from a temporary consumer
repository with these environment values:

```bash
SKILLEVAL_SKILL_PATH=skills
SKILLEVAL_BENCHMARK_PATH=benchmark
SKILLEVAL_MIN_RECALL_AT_K=1.0
SKILLEVAL_MAX_NEGATIVE_HIT_RATE=0.0
SKILLEVAL_OUTPUT_DIR=skilleval-output
GITHUB_STEP_SUMMARY=step-summary.md
```

Expected local result:

- `output/gate-report.json`: `ALLOW_MERGE`
- `output/gate-report.md`: `Decision: ALLOW_MERGE`
- `output/ci-summary.json`: CI summary decision `ALLOW_MERGE`
- `output/ci-summary.md`: GitHub step-summary style Markdown
- `output/results.jsonl`: per-task routing records
