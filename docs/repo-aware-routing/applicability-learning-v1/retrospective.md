# 本轮个人复盘

校准只是调整现有分数到标签频率的映射，不能替代通过任务—技能样本更新语义模型。本轮独立 LoRA 的训练目标直接监督 yes/no logit；是否真的学到条件差异，仍需看未用于选择的机制组，不能用梯度或 loss 下降代替。

通用调试或核验流程能提供具体步骤，因此可以是适用性正例；它通常缺少针对当前接口、格式或约束的帮助，所以在特异性轴为零。这两个判断分开，避免为了制造负例而贬低合理的固定流程。

技能先验捷径要靠对照排查：同一技能跨自然任务是否有正负变化；fit-only 技能先验和仅技能正文的负控制是否已经达到相同表现；便宜词法模型能否胜任。技能正文中存在操作特征不代表模型已经理解仓库，更不意味着需要昂贵模型。

检查集自身的正例比例是在看见检查标签后才知道的。其 p(1-p) 只能是事后参考；可部署常量必须在 fit 中得到并冻结，然后到 check 上算误差。旧字段不改写，只修正新报告的解释。

文本选择只能判断原文步骤的适用与特异性。实际补丁收益必须有同上下文、同目录、同预算的真实执行对照，并记录选中、物化、读取和独立补丁核验。没有合格操作点时，不再用全部回退的 smoke 冒充支持模型有效。用户本人是否掌握这些区别，需要本人讲解或实践，不能由 Agent 代签。
