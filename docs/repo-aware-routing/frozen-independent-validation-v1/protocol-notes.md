# Frozen independent validation protocol notes

The active Goal is [the complete execution contract](../../goals/Hermes_PR48_Frozen_Independent_Validation_Codex_Goal.md). `protocol.json` is the machine-readable first freeze. No new neural training, default promotion, merge, archive or release is authorized.

## Independence and recruitment

Logical `cal_new`/`check_new` use the existing internal split values `cal`/`check`. Each has 12 mechanisms: five sqlite-utils, five csvkit, two csv-diff. All ten frozen skills are paired with every task. A seeded source-specific issue order and public-input eligibility controlled recruitment; full request bodies were available to the controller, including public proposed fixes. Updated issue bodies are current fetched text, not authenticated historical originals. The complete retrieved candidate denominator and exclusions are retained. No method score or weak label was available at recruitment.

Historical scanning covers tracked configs, artifacts, docs and scripts, including earlier requirements, actual repair tasks and skill sources. Mechanism adjudication is a controller judgment; URL/ID matching is only a guard. Fetching a source page in an earlier study is not itself proof that every issue on that page was used, and incomplete private conversational exposure cannot be ruled out. This is new mechanisms in known repositories, not unseen-repository generalization or guaranteed absence from pretraining.

Base snapshots are the latest reachable commit before issue creation. This alone does not establish that a reported bug reproduces. Only the separately qualified repair subset has base-red/reference-green evidence. Full-source SHA-256 manifests and actual isolated probes bind these snapshots. Context extraction is frozen: partial/unavailable contexts remain in the roster and cannot earn support acceptance. Their readable requests and extracted summaries can still have raw advisory scores, with qualification disclosed separately. Legacy original rank keeps its original 1024-token truncation semantics.

## Repair qualification

Four check requests were selected before model scores or labels, based on public behavior and an available reference: sqlite-utils #344, #400, #368 and csvkit #1225. The qualification controller sees reference code and trusted checks; annotation and prediction contexts do not. Checks cover only the listed public behavior and a small protected basic regression, not complete upstream correctness.

- #344: upstream STRICT table implementation at `1500c19`; the reference package includes later upstream changes, so it is a behavioral qualification oracle, not a minimal causal patch. Pluggy 1.6.0 was added to both qualification images to satisfy the reference import. Target execution remains offline and isolated.
- #400: controller-authored `--if-not-exists` alias of the existing `--ignore` behavior. Test requires creation, repeat invocation and preserved rows. This is an authored reference, not a claimed upstream merged fix.
- #368: upstream `539f5ccd90371fa87f946018f8b77d55929e06db` module entrypoint. The request references historical #364, but this fixes module startup, not that earlier batch-commit mechanism.
- #1225: the stdin caching/filename changes from upstream `88753f9f1f756a64ccacae53897b8f85cdfef995`, applied to the selected base.

The failed local-image FROM attempt and the missing reference dependency attempt are retained privately. They are engineering qualification failures, not failed Agent repairs. No repair Agent runs before all empirical triggers hold. The fixed four-task, five-arm, two-repeat matrix uses one shared public context, gpt-5.6-sol/medium, 600 seconds per call, concurrency one and seed-7170 schedule. Provider snapshot and sampling seed control are unavailable; dollar cost is unknown, and no new paid resources are authorized.

## Labels and weights

Two isolated model contexts receive only public requests/context and the complete frozen skill bodies. They do not see split, predictions, methods, thresholds or references. These are same-model weak judgments, not two humans or independent model families. Per-axis disagreement becomes UNKNOWN. Check labels are generated only after check predictions are locked.

Mapping fitting uses eligible, known cal rows, with mechanism/parent/requirement/pair weights after known masking. It reuses the old fixed regularized sigmoid optimization and does not refit the cheap classifier. The inherited slope constraint permits zero. Calibration-internal curves are not generalization evidence. Final probability metrics, acceptance and selected-set metrics are separate; both weighted quantities and raw counts are reported. Empty acceptance has null precision. Bootstrap units are complete repair mechanisms, with undefined acceptance resamples retained.

The explicit probe payload is excluded only from automatic Ruff formatting after
its bytes were used to build the frozen environment images; ordinary lint still
checks it. This repository-local formatter setting preserves the payload hash
and has no scoring or runtime semantic effect. It is an additional delivery
write-scope entry (`pyproject.toml`), not a method or threshold change.
