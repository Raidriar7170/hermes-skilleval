批准的 v2 query contract

唯一 primary query

query_text == task.prompt（loader normalization 后逐字节相等），且 sha256(query_text) == prompt_text_sha256。

显式版本边界

Candidate/report/manifest/policy 全部升级为 v2；row 增加 query_text_policy="prompt_only"。

禁止双 query

不输出 legacy、alternate、metadata-enriched 或 composite query，避免 consumer 继续选择泄漏表示。

ID、category、difficulty、robustness tags 仅用于 validation/classification/split/provenance；category 仍可分类同/跨类别候选。
