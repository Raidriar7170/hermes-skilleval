边界与不要夸大

Failure Gallery 是 navigation layer over committed failure evidence；canonical evidence remains in the linked artifacts。Boundary phrases: not a Marketplace Action, not GitHub API PR comments, not PR annotations, not SaaS, not a runtime MCP router, not a SOTA claim, not benchmark status, not production readiness, not release approval, and not automatic merge approval。
