External Skill Library Validation Pack

archived

一句话结论：本阶段把 diagnostic onboarding 从单一本地 Markdown demo 扩展为一个 external-style evidence pack，覆盖 Markdown skills 与 MCP tool schema 两条 source track，并接入 drift check、validate workflow 与 PR-facing CI summary。

本阶段改动

  • 新增 docs/demo/external-skill-library-validation/，包含 source fixtures 与两条 track 的 scan、lint、inspect、route、dashboard、CI gate、PR review packet artifacts。
  • 扩展 diagnostic_artifact_drift 的目录 artifact list，使它能比较 external pack 的嵌套 artifacts。
  • 更新 ci_summary changed-file grouping，把 external pack 路径归入 diagnostics，并覆盖 external-pack check outcome。
  • 更新 validate workflow：在 $RUNNER_TEMP 再生成 external pack、运行 gate 与 drift check、上传 artifacts，并将 outcome 传给 skilleval ci-summary。
  • 更新 README 与 docs/usage.md，说明本地模拟命令和明确非目标。

不要夸大的点

  • 这是本地 diagnostic evidence pack，不是 Marketplace Action。
  • 不产生 GitHub API PR comments，不写 PR annotations，不是 SaaS。
  • 不是 runtime MCP router，不是 SOTA claim，不是 benchmark status，不代表 production readiness，也不是 release approval。
