PR-6 SkillsBench Live-Agent Matrix

本阶段新增 SkillsBench-shaped adapter、任务冻结计划和三条件 live-agent matrix 基础设施；不运行 full live benchmark，不训练或推广 router。

状态

OpenSpec change：skillsbench-live-agent-matrix。当前实现使用 tiny fixture 和 fake runner/verifier 验证基础设施合同。

本阶段变化

  • 新增 SkillsBenchAdapter，验证 deterministic verifier、无私有凭据、受控网络、oracle skill 定义和 provenance。
  • 新增 pilot/frozen plan writer，记录输入 SHA-256/size、oracle qualification、global skill registry、matrix run entries 和 overlap scaffold。
  • 三条件 no-skill / routed-skill / oracle-skill 复用 PR-4 runtime，保证同一 task 的 prompt hash 一致且每次 run 使用 fresh workspace。
  • matrix report 记录 trace path、skill use evidence、process exit、timeout、verifier result；task success 只来自 verifier。
  • 新增 skillsbench-validate、skillsbench-plan、skillsbench-matrix CLI smoke。
