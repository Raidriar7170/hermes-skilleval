  • README 与 usage 增加本地模拟命令和有界说明。
  • 新增测试覆盖 decision、Markdown、changed-file grouping、CLI wiring、workflow surface 与公开措辞。

边界与风险

  • 这是 local/GitHub Actions summary，不是 GitHub API comment bot、PR annotation system、Marketplace Action、SaaS、runtime MCP router、SOTA claim 或 release approval。
  • Workflow 使用 continue-on-error 后必须依赖最后的 JSON decision enforce；不要删除最终 enforce step。
  • changed-file grouping 是 v1 宽分类，只用于 review summary，不是安全策略。

推荐下一步

本阶段已归档。推荐 push 后检查 GitHub Actions Validate run 的 summary；如需 PR comment bot 或 Marketplace Action，应另开 OpenSpec change。
