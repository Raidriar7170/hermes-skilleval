PR-4: Live-Agent Runtime Fake

状态：needs review

本阶段只新增可测试的 live-agent.v1 fake runtime contract，没有接入真实 Codex CLI、SkillsBench 或 live agent 执行。

本阶段变化

  • 新增 AgentRunner protocol、请求/结果 dataclass、trace schema 和 fake runner/verifier。
  • 新增 no-skill、routed-skill、oracle-skill condition builder，并保持 prompt hash 一致。
  • 请求构造会校验 condition 与 workspace 的 mounted skill ID 有序一致，避免 routed/oracle 或 no-skill workspace 注入错配。
  • 新增隔离 workspace 准备与 skill mount 记录，包含 workspace reuse fail-closed、碰撞安全的 mount 文件名和 mounted skill SHA-256。
  • 将 agent process exit code、timeout 与 verifier pass/fail 分离，task success 只来自 verifier。
  • 记录 MOUNTED_ONLY、READ、DECLARED、UNKNOWN skill-use evidence。
  • 新增 malformed event、unknown event、trace key/value secret redaction、log truncation、no-skill leakage 的测试覆盖。
