External SkillRouter Adapter Provenance

applying / PR-1 adapter only

一句话结论：本阶段新增 SkillRouter 外部数据 adapter、provenance manifest 和 tiny offline fixture；它只验证外部数据能否安全进入后续评测，不产生任何 v0.3 分数、路由结果或默认路由器决策。

当前状态

OpenSpec change：external-skillrouter-adapter-provenance。范围是 PR-1 external adapter/provenance；PR-2 scorer parity、PR-3 routing matrix 和 live-agent runtime 都不在本阶段。

本阶段改动

  • src/hermes_skilleval/external/skillrouter.py：新增 canonical task/skill/relevance records、SkillRouter adapter、validation 和 manifest 写入。
  • src/hermes_skilleval/cli.py：新增 external-validate，只写 manifest.json 和 validation.json。
  • tests/fixtures/external/skillrouter_eval_core_tiny/：新增 official-shaped tiny fixture，覆盖 instruction_text、object-shaped relevance.json、top-level easy//hard/ gzipped shards、generic_only、single-skill 和 multi-skill task。
  • tests/test_external_skillrouter_adapter.py 与 tests/test_cli_external_skillrouter.py：覆盖 canonical loading、metadata preservation、hash manifest、validation failures 和 CLI 行为。

关键边界

  • 不下载或提交完整 SkillRouter 数据。
  • 不计算 official metrics、Hermes Negative Hit Rate 或任何 PR-2 scorer parity。
  • 不运行 routers、embedding models、training、threshold tuning 或 candidate promotion。
  • manifest 记录文件 SHA-256；路径不能替代内容 hash。
  • invalid data 仍写出 validation/manifest，供后续 evidence gate 判断。
