Diagnostic CI PR Review Surface

archived

一句话结论

本阶段把 diagnostic CI gate 的 JSON 结果整理成可给 PR reviewer 阅读的本地 packet，但不接 GitHub API、不写 PR annotations、不发布 Marketplace Action。

本阶段改动

  • 新增 skilleval diagnostic-pr-review-surface，从 diagnostic_ci_gate report 生成 JSON/Markdown review packet。
  • 新增 demo artifacts：pr-review-packet.json 与 pr-review-packet.md。
  • 补充 README、usage docs、demo README，说明本地 review packet 的使用边界。
  • 新增/扩展测试，保护 verdict source、bounded wording 和 committed demo artifact contract。

不要夸大的点

  • 这不是 GitHub API integration，也不写 PR comments 或 annotations。
  • 这不是 GitHub Marketplace Action release。
  • 这不是 SaaS、runtime MCP router 或自动 merge 系统。
  • packet 中的风险项是 review-worthy diagnostic signals，不是 duplicate / unsafe / wrong 的最终裁决。
