External Matrix Generalization

applying / PR-3 matrix only

一句话结论：本阶段新增 frozen zero-shot external evaluation matrix：先写冻结计划，再消费冻结 predictions 做 SkillRouter official Easy/Hard scoring，并把 Hermes stress diagnostics、split、bootstrap、overlap scaffold 分开输出。

当前状态

OpenSpec change：external-matrix-generalization。PR-1 adapter/provenance 和 PR-2 official scorer 是稳定依赖；本阶段不改 scorer 公式，也不运行 router/model/live-agent。

本阶段改动

  • src/hermes_skilleval/external/skillrouter_matrix.py：新增 frozen plan writer、matrix runner、field views、candidate subset sampling、paired bootstrap CI、held-out splits、SkillRouter/SkillsBench overlap scaffold，并在 matrix run 时校验 frozen prediction/data hashes。
  • src/hermes_skilleval/cli.py：新增 external-plan 和 external-matrix 命令。
  • tests/test_external_skillrouter_matrix.py：新增 tiny-fixture TDD tests，覆盖冻结计划、CLI smoke、official/diagnostic 分离、stress subset、bootstrap、split 和 overlap scaffold。
  • openspec/changes/external-matrix-generalization/specs/external-evaluation-matrix/spec.md：定义 PR-3 外部矩阵 contract。

关键边界

  • 矩阵 runner 只消费 frozen prediction files，不训练、不调阈值、不挖 hard negatives、不跑 embeddings/rerankers/model inference。
  • official SkillRouter Easy/Hard results 通过 PR-2 scorer 生成，并按 frozen config_id keyed；candidate-pool stress tests 只在 hermes_diagnostics 中出现。
  • held-out-source metadata 不足时输出 field-level UNAVAILABLE，不伪造 split。
  • SkillRouter 没有显式 negative labels 时不输出 Hermes Negative Hit Rate。

剩余风险

本阶段证明的是 deterministic local machinery 和 tiny fixture path；真实 external matrix 仍需要后续提供冻结预测文件和固定 upstream data root。不要把 stress subsets 描述为 official SkillRouter results，也不要把本 PR 说成 live-agent evidence。
