Diagnostic CI Gate

archived

一句话结论

这一阶段把 diagnostic artifacts 变成可在 CI 中验证的本地门禁：它能按显式阈值阻止 lint findings、conflict clusters、route risk flags 或 route evidence 退化，但不宣传成 Marketplace Action、PR annotation、SaaS 或 runtime router。

本阶段改动

  • 新增 skilleval diagnostic-ci-gate，读取 scan/lint/inspect/route JSON artifacts 并输出 JSON/Markdown report。
  • 在 GitHub workflow 中加入 diagnostic demo gate step，读取已提交 demo artifacts，报告写到 $RUNNER_TEMP，避免 timestamp 导致的不稳定 diff。
  • 新增 demo gate report：docs/demo/diagnostic-onboarding/ci-gate-report.json 与 ci-gate-report.md。
  • 补充 README、usage docs、demo README 和测试，强调 artifact-based CI validation 的边界。
