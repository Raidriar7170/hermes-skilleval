剩余风险和不要夸大的结论

  • P0 heuristics 是本地可解释风险信号，不是 learned judge、runtime router、SaaS dashboard 或公开 benchmark。
  • MCP schema 支持保守的 tools / server.tools 形态；更复杂 schema 应进入后续 OpenSpec change。
  • Diagnostic artifacts 可为后续 labeled regression / CI gate 产品化提供稳定输入，但当前不声称 PR annotation 或合并门禁。
