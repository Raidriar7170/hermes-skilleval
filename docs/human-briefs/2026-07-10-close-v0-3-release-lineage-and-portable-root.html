路径选择与 containment 合约

  1. 选择优先级：--output-root > config 的 output_root > 兼容默认 /mnt/data/minghongsun。
  2. 相对 root：从 trainer 进程的当前工作目录解析，不跟随 config 文件目录。
  3. output_dir：相对值放在 selected root 下；绝对值只有在 canonicalize 后仍被 root 包含时才接受。
  4. Fail closed：拒绝 sibling-prefix、..、绝对路径与现存 symlink 逃逸，并在创建目录或写 model/manifest/summary 前失败。
  5. 一致 provenance：train config、model manifest validation 与 train-run-summary.json 使用同一 canonical root/output_dir。

这是文件系统 containment 检查，不承诺抵御敌对本地用户并发进行的 symlink-swap race。
