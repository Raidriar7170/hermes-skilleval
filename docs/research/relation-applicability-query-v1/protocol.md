本研究执行用户指定的完整 Goal。基线是 PR #54 `342c7fe5239f8edaf993786d1cf05bc548593519`，新 PR 叠加于该未合并分支。默认策略不变；不运行修复 Agent、目标验收或训练。

## 输入与分层

开发状态使用 `development-v5` 的完整要求账本，以及 `fulltext-index-repair-v1` 的最终内容准入候选池。检查状态使用 #54 `study-v1/selection` 的原 ledger/pool。完整域分别为 312、192、336、144 对，各自原24候选、完整要求权重、1200-token包上限与原目标不变。每状态48对在生成本轮标签前冻结，种子20260923；相关层、近似干扰层、分布控制层各16对。相关层由 R 构造，不能据混合面板宣称全域优势。

无标签的文本特征使用冻结 MiniLM 完整分块、按要求归一化 BM25、索引中可解析且无歧义的符号/完整路径、按类型区分的显式条件线索。此版本不推断新的动态调用边。软分不进入关系标签或上下界。分数不是校准概率。

## Q/J 与支持的含义

Q、J 各使用独立新空 thread；J 只接收公开要求与来源，不接收 Q、方法名、分数或查询次序。两者均使用既有 `gpt-5.6-sol / medium`。`human_reviewer_count=0`，同模型仍可能产生相关错误，参考级别固定为 `MODEL_ASSISTED_SOURCE_AUDIT_NOT_HUMAN_GOLD`。

机械引用校验复用原 RelationStore。固定比较规则先要求双方合法：同为明确零记 CORROBORATED_ZERO；正/零或关系角色/适用性冲突记 DISPUTED；正关系同类且相同原文引用锚点、相同显式条件文字线索，才记 SUPPORTED_POSITIVE。锚点不同可能都合理，故保留 REVIEW_UNKNOWN，不凭不同措辞判错，也不重抽求一致。这个保守一致性规则可能低估正确但引文不同的支持，并不能证明逻辑等价。语义未知、机械拒绝、缺失与未抽样全部保留。

封存回放的 worker 通过 macOS sandbox-exec 被拒绝读取 reference 与 online-review 路径，启动时实际测试 Q/J 拒读；监督进程只经管道发送本次请求的 Q 行。排序器不接收 J。面板外关系保持未知。

## 计时与获取

20批传输测量使用同8对开发材料，四配置各两序列，固定种子打乱全部8序列。该随机顺序前两序列恰为相同配置的两个重复，属于已记录的顺序限制；不择优删除或重新抽顺序。每批均新建空线程；复用仅指进程/连接。记录完整序列、初始化、thread创建、响应、解析、取消和清理。没有暴露可验证的首token边界时保持空值。此小样本不报告可靠p95。

适配选择只依据两种生命周期的总合法行/完整序列秒；批量候选2/8。采用同类观测的保守时间包络，超长输入按长度比例放大，预测与最新可比耗时取大。冷实例计初始化，每批计划时间乘1.25，另保留5秒结束余量；不能容纳批次时返回当前包。1对批次参照2对成本。批次异常后确认终止，格式/传输缺失在预算内最多续接一次，首次有效零/正/语义未知/拒绝提议均不重抽。该续接上限是单轨迹运行规则，不限制工程排障。

每条在线轨迹独立空store、独立启动费用，总60秒且最多48个不同配对。公共特征、原候选及MMR材料预先可用，准备耗时单列；选择器构造/求解与关系调用均计入在线时间。使用模型当前 advertised identity，固定 CLI 0.154.0 与继承镜像，不替换模型/effort。

在线锁定后每状态最多128个不同原文配对核对：请求集合不超过额度则全查，超过则固定种子无放回抽样；剩余额度均匀补查最终包/MMR包的来源配对。未入样记 REVIEW_NOT_SAMPLED，包中未查关系保持未知。核对者不看到包/方法身份，仅看到原文配对。

## 归因与停止

请求数回放隔离纯顺序，正式在线包含响应差异与实际开销。正关系数量按不同配对计数，请求位置分母包含重试。分层结果、有效行、争议/未知/缺失、完整权重分母分别报告。非MMR包只证明决策改变；同MMR包不说明所有知识被保留。本轮 `functional_repair_gain=NOT_TESTED_THIS_STAGE`。

冻结之后不得按结果调整系数、提示、模型、候选或截止。工程修复保留原记录并显式绑定版本，不覆盖原研究格。最终仅交付 Draft PR，不合并、不转ready、不发布。
