# 一页架构复盘：从静态检索到一次状态干预

本轮把技能使用建模为：面对当前可见状态，立即注入一个技能、保留机会，或最终不干预。旧 Hermes 检索和整任务结果提供研究动机，没有提供任意中间状态的反事实标签。新实验独立于 PR #48，保持原默认策略。

**架构路径。** 原生执行在 E0 起点、E1 首次公开失败、E2 候选交付或预算 75% 的自然边界产生状态。状态仅包含当前请求、源码/差异、公开工具反馈、阶段和剩余预算。官方会话 fork 加独立源码/临时目录快照建立相同可观察前缀；它不复制隐藏随机状态。每个动作尾程扣除已经消耗的前缀预算，复制、评分和模型初始化也计入原 600 秒。隐藏检查在相应 Agent 执行结束后提供标签。

**为什么学相对增益。** “看起来相关”不等于能改善当前解题过程。训练目标是技能尾程效用减同前缀不干预尾程效用，保留质量、时间和提示长度分项。实际收集 180 条尾程，其中 178 条有效、2 条未知；12 个训练机制产生 80 条聚合监督样本。冻结 MiniLM 编码器与轻量交互头组合状态和技能向量，进行真实 CPU 参数更新，保存权重后在独立进程重载。另行训练 no-state 和 state-only 诊断，避免把部署时遮住特征冒充独立学习。

**为什么只允许一次干预。** 一次预算把“用哪个技能”和“何时用掉机会”连接起来，同时限制额外提示量和执行资源。WAIT 保留未来机会；终点 no-op 则放弃外部干预。等待头沿不干预轨迹学习下一状态的预测价值，嵌套排除整个目标任务，既不以已实现的未来最优分支作标签，也不在在线决策读取未来。最终策略只执行自己选中的一条轨迹。

**实际结果。** 12 训练 / 4 开发 / 8 测试，六种策略各两次，96 条测试全部完成。N0、静态、规则、myopic、no-state、full 的合格补丁分别为 9、9、11、12、10、12 / 16。96 条目标检查和保护回归全部通过，合格率差异全部来自文件策略违规；不能称为语义修复率提升。Full 对 N0 的复合效用差为 +0.182，八任务描述性 bootstrap 区间 [0.053, 0.368]，属于有限样本观察。Full 与 myopic 合格数持平、平均效用略低；对其他基线的区间均跨零。

**学到了什么，尚未证明什么。** 真实参数更新、重载和在线等待评分均已实现。Full 等待头参与 26 次评分，但没有观测到正增益注入被等待值拦下，当前 WAIT 也可由立即增益非正解释。因此未建立状态或等待的独立收益，也未证明专业技能胜过一般提醒。开发集廉价 skill/stage prior 的预测误差优于 full。E0 未观察到质量救回；训练 #339 的同一技能在 E0 有害、E2 才出现文件策略复合救回；开发 #368 所有动作通过时，不干预避免额外成本。这些是保存的随机执行样本，不是可泛化的时机因果证明。

**工程与边界。** 新增薄适配、状态控制器、学习和可重算入口，沿用隔离及验收；没有新建产品或审计平台。冻结数据与模型后完成全部比较，没有因结果不佳换题、追分或补送预算。四个训练 CSV 检查适配器的版本化修复、两个未知样本和一次过载均保留披露。原始补丁与固定验收随证据包交付，私密会话、全量源码和权重不进入 Git。结论为 `OBSERVED_GAIN_WITH_LIMITATIONS`，仅限文件策略复合验收的观察；`KEEP_EXISTING_DEFAULT`。不主张学术首创，不合并、不发布、不升级默认策略。
