# Evidence-linked local retrieval v1

本研究从 PR52 的实际 HEAD `86356edbc42c1116c93df38576357ce7d3625e5a` 叠加实施。主指标为原候选的可信目标与保护检查，不以引用、覆盖分或测试数量代替功能收益。旧四状态只用于开发；旧56次执行及其结果不重跑、不改判。

## 输入与算法

账本的行级覆盖不是去重后的唯一语义义务覆盖率。完整公开题面按保留条件的段落/bullet/接口声明进入账本；运行环境说明与无法解析片段显式留在 unresolved。概述可能与详细要求重复，有限来源核对必须指出此表示限制。功能权重按父要求归一后分摊。观察仅接受检查点可见事件，同命令同来源版本的可比成功才能 supersede 失败；未知/复合命令使来源版本未知，后续修改使旧支持陈旧。退出0本身不证明全部公开要求。

最终实现按 UTF-8 文本内容准入，不再按后缀筛选。每个合法 base 全量枚举一方源码、文档、已有公开测试，分别记录 vendor、generated、binary、symlink、未来版本说明等排除。元数据不设40项上限；源码方言解析失败仍保留元数据。查询逐要求最多8种子、一跳每种子最多4真实边、最多128完整可装包视图，统一得到24候选。冻结MiniLM完整分块编码，词法/向量/符号权重为0.3/0.6/0.1。超长或缺失闭包上下文的源码保留元数据但不装包。

M-local、H-sim、H-link共享账本、候选、来源角色、序列化模板、1200 tokens与4单元上限。H-sim与H-link只替换覆盖矩阵：后者使用固定模型提议并校验引用/角色/条件的关系权重。非法提议原样保留但权重0，不重采样选标签。关系不是形式证明。冻结输出采用完整pair矩阵的紧凑行：正关系必须给精确引用/适用性/依据；零关系短行不宣称适用性，其出处跨度由输入机械补全并明确不是模型选取的证据。此为传输压缩，不把未输出的pair默认判正或删除。没有任何正关系时H-link明确无支持上下文，不将其他方法的结果冒认为H-link。

## 开发诊断与来源核对

四个已观察旧状态保留初版和各修复版。固定消融为：同完整索引旧摘要query/新账本query；同新query旧40项/全索引；同新query和全索引关闭/开启一跳；同池三选择器。消融没有新修复执行，历史摘要投影不是历史Agent重放。

独立只读模型上下文先检索原文锚点，再读取打乱且隐去方法/分数的候选和包。报告支持、反对、未知；锚点不完备，命中不是完整仓库召回率。human_reviewer_count=0；基础模型/训练来源相关误差仍可能存在。

## 预登记小型功能验证

在新功能结果出现前，按旧六项 roster 的 source_order 和独立关键合同覆盖核对选定 documentation-macro-boundaries 与 variable-file-cache。其余四项保留 REVIEW_REQUIRED 原因，六项均已机械验证 base目标FAIL/保护PASS、reference两者PASS；reference和隐藏内容只用于隔离验收，不进入算法。两项的题面/base此前准备时可能已见，不能称未见仓库泛化。

每题一次原生公开前缀，首个完成轮次含任务相关源码/公开检查观察即保存；若只在交付得到边界，记录晚期状态。每状态N/M-local/H-sim/H-link各2尾程，固定种子20260921交错，共计划2前缀+16尾程，最多18研究执行。无结果驱动替换或重抽，未执行/中断仍保留全部16计划分母。

模型gpt-5.6-sol、medium、总600秒继承。每臂扣除相同实际索引时间、编码器加载、检索、关联提议、关系提议及全部选择器时间；克隆/启动继续在各尾程计时。该公平收费不是线上原生延迟估计。独立来源评测另计。若预处理耗尽预算，明确UNKNOWN且不启动假尾程。真实API调用数包含另列的语义分析与审阅，不能用18表示项目总调用。

冻结计划绑定源码/脚本、参数、模型文件、任务公开输入、base/验收身份、实际可信overlay、公共索引、skills和镜像。冻结后先生成新预测与包，再独立盲核对；核对不能改权重、提示或手工补包。可执行但选差仍按固定计划比较。

## 终端判定与报告

全部尾程终结或明确中断且无运行进程后才释放隐藏检查。原候选与安装可信测试的验收副本分开，保留原补丁；完整性未确认为UNKNOWN，可信目标或保护FAIL即FAIL，两者有效PASS才PASS，否则UNKNOWN。文件策略独立记录，不改变功能标签。旧报告入口和语义保持不变。

每机制先对两重复计PASS/FAIL/UNKNOWN/计划数，下界PASS/计划，上界(PASS+UNKNOWN)/计划；机制等权均值和差值上下界保留未知，不作小样本总体认证。H-link−M-local是选择收益主比较，H-link−H-sim是关系作用比较，M-local−N是组织资料比较。无功能增益允许研究完成，默认UNCHANGED、无训练、无合并/ready/发布。
