## ADDED Requirements

### Requirement: Observable-prefix continuation
The adapter SHALL save completed visible history, independent source and scratch snapshots, environment identity and remaining global budget; all actions SHALL continue from the same observed prefix.

#### Scenario: Paired branches
- **WHEN** an intervention and native tail start from a checkpoint
- **THEN** they receive equal remaining budgets and isolated identical initial files, and native continues reasoning and editing.

### Requirement: Real incremental utility learning
The system SHALL fit gain to actual terminal quality and cost differences against native continuation; invalid or missing runs MUST NOT become negative labels. State MUST exclude future and hidden observations.

#### Scenario: Missing verification
- **WHEN** a tail lacks valid external acceptance
- **THEN** its gain label remains unavailable and its record remains in the denominator.

### Requirement: Learned waiting with one intervention
The controller SHALL compare current gain, task-cross-fitted waiting value and zero, using only current observations, and SHALL inject at most once. Models SHALL update parameters and reload for inference.

#### Scenario: Preserve opportunity
- **WHEN** waiting value exceeds current positive gain
- **THEN** the policy continues without injection and preserves the single intervention budget.

### Requirement: Frozen comparisons
The study SHALL freeze task-level partitions, repeats, budget and methods before test outcomes, run native/static/rule/myopic/no-state/full methods, and preserve failures, no-ops, unknowns and actual patches.

#### Scenario: No learned gain
- **WHEN** learned methods choose no intervention for every task
- **THEN** the planned comparisons still run and no utility gain is claimed without evidence.
