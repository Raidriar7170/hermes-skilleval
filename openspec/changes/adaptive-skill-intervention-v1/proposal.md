## Why

The previous static skill pilot did not establish repair utility. The active Goal requires testing whether visible execution state and the option to wait improve a single explicit skill intervention relative to native continuation.

## What Changes

- Add observable-prefix session branching with independent source/scratch snapshots and shared remaining budgets.
- Collect real paired tail executions, fit state–skill incremental utility and task-cross-fitted waiting value, and reload models for actual online decisions.
- Freeze and execute native/static/rule/myopic/no-state/full comparisons, retain failures and unknowns, and provide replay and an architecture retrospective.

None. Existing defaults and historical research remain unchanged.
