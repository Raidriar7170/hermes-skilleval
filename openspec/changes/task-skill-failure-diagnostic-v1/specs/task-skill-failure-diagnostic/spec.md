## ADDED Requirements
### Requirement: Frozen development diagnostics
The study SHALL preserve the complete Goal, old results and ten skill bodies, and freeze ordered public sources before new Agent results.
#### Scenario: Qualification fails
- **WHEN** a source or environment is not qualified
- **THEN** record the reason and use only a preregistered mechanical reserve, never replace native success.
### Requirement: Native difficulty precedes intervention
The study SHALL probe each admitted mechanism twice with the inherited model and 600-second budget, registering visible checkpoints before hidden terminal scoring.
#### Scenario: All native probes pass
- **WHEN** all admitted native trajectories pass
- **THEN** report NO_NATIVE_FAILURE_OBSERVED and do not launch the full tail matrix.
### Requirement: Real same-state controls
The study SHALL freeze up to three failed mechanisms and one success control in task order, select K from public prefix information only, and execute N/G/K twice from identical observable state and remaining budget.
#### Scenario: No supported skill
- **WHEN** no existing payload has evidence-supported applicability
- **THEN** K remains not executed and cannot count as no-op success; N/G controls remain available.
### Requirement: Functional evidence and immutable attempts
The study SHALL reuse pure functional target and protected-regression labels, preserve UNKNOWN and interrupted cells, and compare actual tails rather than screening native labels.
#### Scenario: Faster tied skill
- **WHEN** K and N both pass but costs differ
- **THEN** functional difference remains zero.
#### Scenario: Resume
- **WHEN** an attempted cell already exists
- **THEN** reuse its saved evidence or preserve interruption, never sample a replacement.
