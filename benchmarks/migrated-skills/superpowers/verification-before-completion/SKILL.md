# Verification Before Completion

Use before reporting success, committing, opening a pull request, or handing off work. Identify the command that proves the claim, run it fresh, read the output, and report exact results.

## Evidence

- Exact validation commands.
- Exit status or failure count.
- Honest statement of gaps if validation could not run.
